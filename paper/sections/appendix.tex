\section{Reproducibility}
\label{app:repro}
% DRAFT (Claude): awaits the author's rewrite.

All settings are in the repository's configuration files:
\texttt{configs/pilot.yaml} for the data filter and the Markov state model,
\texttt{configs/judge.yaml} for the judge models and prompt limits, and
\texttt{configs/search.yaml} for the prover, and
\texttt{configs/search\_eval.yaml} for the search budget and conditions. The proof
sample, the clustering and the bootstrap use fixed seeds. The
model was fit on an Apple M2 Mac Mini with 16 GB of memory; the prover ran
behind vLLM on an AWS g6.xlarge instance. The judges ran through the Anthropic
Message Batches API with a spending cap of \$85 per submission.
